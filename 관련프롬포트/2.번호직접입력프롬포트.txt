## 2. 번호 직접 입력 프롬프트

특정 번호의 문서를 만들고 싶을 때 사용한다.

아래의 `031` 부분만 원하는 번호로 바꾼다.

```text
PROBLEM-INDEX.md의 031번 주제를 생성해라.

작업 전에 README.md, AGENTS.md, PROBLEM-INDEX.md를 다시 확인하고 AGENTS.md의 규칙을 모두 적용해라.

작업 순서:

1. PROBLEM-INDEX.md에서 031번의 주제, 상태, 분류를 확인한다.
2. 번호와 주제에 맞는 저장 폴더와 파일명을 결정한다.
3. 동일한 번호 또는 동일한 파일명의 문서가 존재하는지 확인한다.
4. 파일이 이미 존재하면 덮어쓰지 말고 작업을 중단한 뒤 기존 파일 경로를 보고한다.
5. 파일이 없으면 031번 문서 하나만 생성한다.
6. AGENTS.md에 정의된 문서 템플릿을 빠짐없이 적용한다.
7. 기술 설명은 개념, 등장 배경, 내부 동작, 장단점, 성능, 실무 사례 순서가 자연스럽게 이어지도록 작성한다.
8. Java 예제는 Java 21을 기준으로 작성한다.
9. Spring 예제가 필요한 경우 Spring Boot 3.x를 기준으로 작성한다.
10. 코드가 본문의 설명과 일치하는지 확인한다.
11. 관련 문서가 실제로 존재할 때만 Obsidian Wiki Link를 추가한다.
12. 유용한 경우 Mermaid 다이어그램을 포함한다.
13. 기술적 오류, Mermaid 문법, Markdown 구조를 자체 검토한다.
14. 생성이 완료되면 PROBLEM-INDEX.md에서 031번의 상태만 ⬜에서 🟨로 변경한다.
15. 다른 번호와 파일은 수정하지 않는다.

완료 후 다음 내용을 보고하라.

- 생성한 문서 경로
- 수정한 파일
- 문서 번호와 주제
- 자체 검증 결과
- 추가 검토가 필요한 부분
```

### 간단 명령

Codex가 번호 명령을 안정적으로 처리하도록 설정된 후에는 아래처럼 짧게 입력할 수 있다.

```text
031
```

또는:

```text
031번 생성
```
