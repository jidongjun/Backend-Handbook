## ChatGPT 리뷰 반영

```text
아래는 ChatGPT가 현재 문서를 검토한 결과다.

[여기에 ChatGPT 리뷰 내용을 붙여 넣는다]

위 리뷰를 현재 문서에 반영해라.
 
규칙:

1. 리뷰 내용을 무조건 적용하지 말고 기술적으로 타당한지 확인한다.
2. 명백한 기술 오류를 가장 먼저 수정한다.
3. 기존 문서의 좋은 설명과 구조는 유지한다.
4. 부족한 내부 동작, 실무 사례, 성능 관점을 보완한다.
5. 코드와 본문의 설명이 일치하도록 수정한다.
6. Java 21 및 Spring Boot 3.x 기준을 유지한다.
7. 중복되는 설명은 정리한다.
8. Mermaid와 Wiki Link를 다시 검증한다.
9. 다른 문서는 수정하지 않는다.
10. PROBLEM-INDEX.md 상태는 🟨로 유지한다.

완료 후 리뷰 반영 내역과 제외한 의견이 있다면 그 이유를 보고하라.
```
